# IEEE-CIS Fraud Detection REST API Specification

The backend service is implemented in Flask (`backend/app.py`) providing a RESTful JSON interface for health monitoring, transaction classification, model explainability, risk stratification, and prevention recommendations.

## Base URL
- **Local Development:** `http://127.0.0.1:5000`
- **Via Angular Proxy:** `http://localhost:4200/api`

---

## 1. Health Check Endpoint

### Request
- **Method:** `GET`
- **Path:** `/health`
- **Headers:** None required

### Response (200 OK)
```json
{
  "status": "ok",
  "service": "IEEE-CIS Fraud Detection API",
  "model_loaded": true,
  "features_count": 68,
  "model_type": "RandomForestClassifier"
}
```

---

## 2. Fraud Prediction & Risk Analysis Endpoint

### Request
- **Method:** `POST`
- **Path:** `/predict`
- **Headers:** `Content-Type: application/json`

### Request Body Schema
The request payload accepts a JSON object with any or all of the 68 model features. Omitted fields are automatically imputed using precomputed population medians from the training dataset.

> [!CAUTION]
> The prediction target column (`is_fraud`, `fraud`, `target`, `label`) must never be submitted as a predictor. If present, the API will strip it before inference to prevent data leakage.

#### Example Request Body
```json
{
  "transaction_amt": 500.0,
  "product_cd": "W",
  "card4": "visa",
  "card6": "credit",
  "card1": 6580.0,

  "purchaser_email_domain": "gmail.com",

```

## 3. Error Responses

### 400 Bad Request — Non-JSON Body
```json
{
  "error": "Request Content-Type must be application/json."
}
```

### 400 Bad Request — Invalid Data Type
```json
{
  "error": "Validation failed on feature payload.",
  "details": [
    "Invalid numeric value for field 'transaction_amt': received 'invalid_amount'"
  ]
}
```

### 405 Method Not Allowed
```json
{
  "error": "Method not allowed on this endpoint."
}
```

### 404 Not Found
```json
{
  "error": "Endpoint not found."
}
```

---

## 4. Example cURL Invocations

### Health Probe
```bash
curl -X GET http://127.0.0.1:5000/health
```

### Prediction Request
```bash
curl -X POST http://127.0.0.1:5000/predict \
  -H "Content-Type: application/json" \
  -d @backend/test_payload.json
```
